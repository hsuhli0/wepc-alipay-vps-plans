## 退款规则：3 天和 10GB 是两个硬门槛

WePC 的退款条件写得比较细，下单前值得先看清楚：

- 使用不超过 3 天，且流量不超过 10GB：可以全额退到账户余额，或者扣 10 元手续费后原路退回。
- 超过 3 天，或者流量超过 10GB：不能原路退款，只能按比例扣除已用部分后退到余额，余额不能提现。

换句话说，想退款要趁早，而且拿到机器后别急着跑大流量测试。10GB 听着不少，但如果你一开机就跑测速、拉几个 GB 的镜像、传几段视频，很容易就过了线。比较稳妥的做法是开通后先确认 IP 属性、ping 一下线路、跑个小文件测试，确认没问题再正式投入使用。

这条规则和不少商家的“48 小时无条件退款”不一样，它多了一个流量上限。买之前先想清楚自己是要长期用还是试一试，试的话把流量控制住。
